01 / RESUMEN

Propósito y alcance

Este proyecto es una plantilla de currículum y portfolio de una sola página, construida con HTML, CSS y JavaScript nativo del navegador. Se puede abrir directamente en el equipo, sin servidor, herramientas de compilación, instalación de paquetes ni Node.js.

La información de partida presenta a Diego Martínez Martínez, de 18 años, estudiante de un ciclo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma entre septiembre de 2026 y junio de 2028. El perfil expresa su aspiración de crear aplicaciones útiles que ayuden a innovar sistemas obsoletos y su aprendizaje de HTML, CSS y Java.

Honestidad del contenido: las ideas de proyectos se identifican como conceptos y las habilidades personales como fortalezas que se quieren desarrollar; no se presentan como productos publicados, experiencia laboral o conocimientos técnicos avanzados.
02 / EXPERIENCIA

Secciones y funciones

  • General: presentación, fotografía, acceso al perfil de GitHub, formación en curso y emblemas visuales de HTML, CSS y Java.
  • Sobre mí: perfil personal, objetivo profesional, resumen formativo y cronología.
  • Habilidades: tecnologías en aprendizaje, etiquetas del nivel inicial y fortalezas personales en desarrollo.
  • Proyectos: tres conceptos de producto claramente diferenciados de trabajos reales.
  • Intereses: innovación, aplicaciones con propósito, modernización de sistemas y accesibilidad.
  • Idioma y apariencia: controles para cambiar entre español e inglés, y entre tema claro y oscuro.

La barra de navegación cambia las secciones sin recargar la página. En pantallas estrechas se adapta a una barra horizontal superior. Los controles se pueden utilizar con ratón, teclado y lectores de pantalla mediante etiquetas y estados accesibles.

03 / DISEÑO

Dirección visual y accesibilidad

La identidad visual combina una base cálida de tonos neutros con un acento lima; tipografía de titulares con personalidad, tarjetas modulares, líneas finas, ilustraciones geométricas y microdetalles de inspiración editorial. El diseño mantiene una jerarquía clara, espacios amplios y controles distinguibles.

  • Adaptación a escritorio, tablet y móvil mediante reglas CSS responsivas.
  • Alternativa de movimiento reducido según las preferencias del sistema operativo.
  • Indicadores de foco de teclado, etiquetas accesibles en controles y descripción de la foto.
  • Las preferencias de idioma y tema son temporales y no se envían a ningún servidor.
  • La tipografía utiliza fuentes habituales del sistema con alternativas locales; no necesita descargar recursos tipográficos ni conectarse a Internet.

05 / USO Y MANTENIMIENTO

Abrir, editar y publicar

  1. Para verlo localmente, abre index.html en un navegador moderno. Mantén juntos este archivo, styles.css, app.js y photo.jpg.
  2. Para cambiar texto o actualizar los datos personales, edita index.html. Para añadir traducciones equivalentes, edita el diccionario translations.en de app.js.
  3. Las interacciones se implementan con JavaScript estándar integrado en el navegador: no se necesitan Node.js, npm, frameworks, compiladores ni instalaciones.
  4. En la sección General, el botón «Descargar currículum» descarga el archivo local CV_Diego_Martinez.pdf. Su documento fuente es curriculum.html; para editar o actualizar los datos del PDF, modifica esa fuente y vuelve a exportarla a PDF.
  5. El CV para descargar es una versión resumida de una página con formación, tecnologías indicadas expresamente como aprendizaje, fortalezas personales, objetivo e intereses. No atribuye experiencia laboral ni presenta ideas de proyecto como trabajos realizados.
  6. El enlace configurado lleva a https://github.com/diegomm1. Los enlaces externos se abren en otra pestaña.
  7. robots.txt solo tiene efecto cuando se publica en la raíz de un servidor web. No hace que un archivo local sea descubrible ni ofrece seguimiento analítico; para publicar el sitio hay que añadirlo también a la raíz del dominio.
  8. La web no envía formularios ni recopila información personal. El control de idioma y tema no guarda preferencias entre sesiones.

07 / ACTUALIZACIÓN Y NUEVO ENCARGO

Descarga del CV y documentación revisada

A petición del usuario, añadí un botón de descarga destacado en la vista General. El botón enlaza directamente al PDF del currículum y utiliza la descarga nativa del navegador, sin un servicio externo ni bibliotecas.

Para entregar un documento listo para descargar, preparé un CV compacto de una página y lo exporté a CV_Diego_Martinez.pdf. La fuente editable curriculum.html conserva el diseño visual y los datos del perfil: fotografía, formación 2026–2028, conocimientos iniciales de HTML, CSS y Java, fortalezas personales, objetivo e intereses. Los conceptos de proyectos se describen como ideas, no como experiencia profesional. El botón de descarga está traducido al inglés al cambiar el idioma de la web.

También añadí este encargo a la documentación y actualicé su PDF para que detalle los archivos nuevos y la forma de actualizar y volver a exportar el currículum.
